Each instruction is stored as one memory word: opcode × 100 + operand. Example: LOAD 10 is stored as 110. Use DATA address value to put a starting value in memory, label: to name a line, and ; for comments.

Theory: the instruction cycle

Fetch: the CPU copies the address in PC to MAR, reads that memory word into MDR, moves it to IR, and increments PC.

Decode: the control unit splits IR into an opcode and an operand and decides what to do.

Execute: the CPU carries out the instruction (memory access, ALU operation, jump or output). Then the cycle repeats with the next instruction.
